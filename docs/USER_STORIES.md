# User Stories Catalog

## Epic: Smart Size & Fit Intelligence (EPIC-01)
- **US-01: Recommended Size Badge on Apparel PDP**
  - *Role*: As an apparel shopper uncertain about sizing,
  - *Need*: I want an automated recommended size badge based on my historical orders,
  - *Value*: So that I can purchase with confidence and fit-related returns decrease.
  - *Estimate*: 5 Story Points | Owner: Rohan Verma | Sprint 42.

- **US-02: Interactive Size Measurement Chart Modal**
  - *Role*: As a customer comparing garment dimensions,
  - *Need*: I want to toggle chest, waist, and length measurements in inches and centimeters,
  - *Value*: So that I can evaluate fit against my exact body measurements.
  - *Estimate*: 3 Story Points | Owner: Ananya Iyer | Sprint 42.

## Epic: First-Party Telemetry Pipeline (EPIC-02)
- **US-03: Native PostgreSQL Event Ingestion Endpoint**
  - *Role*: As a Product Analyst,
  - *Need*: I want first-party telemetry events stored in PostgreSQL without third-party trackers,
  - *Value*: So that funnel conversion metrics remain 100% compliant and unblocked.
  - *Estimate*: 8 Story Points | Owner: Diya Patel | Sprint 41.

## Epic: Post-Purchase Reverse Logistics (EPIC-03)
- **US-04: 1-Click Doorstep Instant Replacement Swap**
  - *Role*: As a customer who received an ill-fitting garment,
  - *Need*: I want a replacement size dispatched immediately while courier collects the original,
  - *Value*: So that exchange turnaround drops from 10 days to under 48 hours.
  - *Estimate*: 8 Story Points | Owner: Vikram Rao | Sprint 43.\n
