# Competitive Analysis & Benchmarking Matrix

## Audited Competitors
1. **Ajio**: Strong indie artisan curation; cluttered filters; 7-10 day return lag.
2. **Zara**: Global benchmark for clean editorial photography and 'What is my size?' widget.
3. **Nykaa Fashion**: Content-led influencer commerce; multi-step cart friction.
4. **H&M**: Affordable sustainable fashion; member loyalty integration.
5. **Meesho**: Dominates unbranded value apparel; sparse sizing guidance.
