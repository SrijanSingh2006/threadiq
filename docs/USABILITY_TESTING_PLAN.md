# Usability Testing Plan & Task Protocols

## 1. Overview
Evaluates the usability, comprehension, and completion velocity of key storefront workflows using the ThreadIQ prototype.

## 2. Testing Scenarios & Tasks
- **Task 1: Sizing Discovery**
  - *Scenario*: You are shopping for a navy blue casual shirt for an upcoming dinner. Find a shirt in size M and use the Smart Size Guide to verify chest fit.
  - *Success Criteria*: User opens Size Guide, checks recommendation badge, and adds size M to bag in < 90 seconds.
- **Task 2: Spec Comparison**
  - *Scenario*: Compare two cotton tops side-by-side to determine which has higher customer rating and better return policy.
  - *Success Criteria*: User adds both to Comparison Drawer and reviews attributes.
- **Task 3: Instant Exchange**
  - *Scenario*: You received an order that is too tight around the shoulders. Request a 1-click doorstep exchange for Size L.
  - *Success Criteria*: User locates order tracking, initiates exchange, and selects replacement size.

## 3. Metrics Captured
- Task Completion Rate (Target > 90%).
- Time-on-Task (Seconds).
- Error Rate & Misclicks.
- System Usability Scale (SUS) Score (Target > 80).\n
