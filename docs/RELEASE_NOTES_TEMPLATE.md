# Release Notes Format Specification

## Header
- **Version**: [e.g., v2.4.0-prod]
- **Release Name**: [Summer Discovery Release]
- **Release Owner**: [Product Manager]
- **Target Launch Date**: [YYYY-MM-DD]

## Sections
1. **Executive Overview**: High-level business impact and goals.
2. **New Features**: Bulleted breakdown of shipped capabilities.
3. **Operational Impact**: Specific SOP updates and customer support briefs.
4. **Known Limitations**: Documented edge cases scheduled for future patches.\n
