# Problem Statements & Friction Framework

## Primary Problem 1: Sizing Uncertainty & Double-Ordering
- **Customer Symptom**: Shoppers ordering apparel on fashion marketplaces cannot reliably determine fit between regional ethnic brands (e.g., Anouk, W) and standard western brands (e.g., Roadster, Mango).
- **Observed Behavior**: Customers frequently buy multiple sizes (Size S and M) of the same garment with the deliberate intent of returning the ill-fitting one.
- **Business Impact**: Drives return rates up to 24.2% in ethnic categories, increasing reverse courier costs, inventory lock-up, and garment wear-and-tear.

## Primary Problem 2: Daylight vs Studio Color Distortion
- **Customer Symptom**: Fabric textures and subtle color hues appear significantly different under natural daylight compared to studio lighting.
- **Business Impact**: 19% of return reasons cite 'Fabric feel or color differs from photos'.

## Primary Problem 3: Payment Gateway Layout Shift on Mobile
- **Customer Symptom**: Asynchronous loading of UPI payment options causes an 850ms Cumulative Layout Shift (CLS) on mobile viewports.
- **Business Impact**: 4.2% drop-off at the final checkout payment step.\n
