# Customer Journey Map: 10-Stage Commerce Experience

## 1. Homepage Discovery
- **Activity**: Browses trending carousels, banner promotions, curated collections.
- **Emotion**: Excited / Hopeful.
- **Friction**: Generic banners irrelevant to user style preferences.
- **Opportunity**: Dynamic segment-personalized hero carousels.

## 2. Search & Query
- **Activity**: Types keywords or colloquial terms.
- **Emotion**: Hopeful.
- **Friction**: Zero-result pages on vernacular terms ('Haldi dress', 'Baggy cargo').
- **Opportunity**: Semantic query expansion with fashion synonym dictionaries.

## 3. Product Listing (PLP)
- **Activity**: Applies multi-attribute filters (size, price, brand).
- **Emotion**: Focused.
- **Friction**: Filter parameters reset when navigating back from PDP.
- **Opportunity**: Sticky filter memory in URL and localStorage.

## 4. Product Detail Page (PDP)
- **Activity**: Examines image zoom, reads descriptions, checks delivery estimates.
- **Emotion**: Curious / Analytical.
- **Friction**: Studio lighting masks daylight color and fabric weight.
- **Opportunity**: Dual-lighting preview (Studio vs Natural Daylight).

## 5. Size Selection
- **Activity**: Toggles size chips, evaluates size chart.
- **Emotion**: Anxious (Fear of ill fit).
- **Friction**: Measurement discrepancies between ethnic and western brands.
- **Opportunity**: Smart Size Predictor badge with fit-history prediction.

## 6. Cart Review
- **Activity**: Reviews items, tests discount coupons, checks total payable.
- **Emotion**: Hopeful.
- **Friction**: Hidden platform fees added at payment step.
- **Opportunity**: Transparent fee breakdown with free-shipping progress indicator.

## 7. Checkout & Payment
- **Activity**: Selects delivery address and payment instrument.
- **Emotion**: Focused.
- **Friction**: Layout shift on UPI selection and delayed OTP delivery.
- **Opportunity**: Pre-cached single-page checkout sheet.

## 8. Fulfilment & Dispatch
- **Activity**: Receives dispatch notification SMS, checks tracking ETA.
- **Emotion**: Anticipating.
- **Friction**: Unnotified warehouse dispatch delays.
- **Opportunity**: Automated milestone tracking webhooks.

## 9. Doorstep Delivery
- **Activity**: Receives parcel, inspects packaging, tries on garment.
- **Emotion**: Delighted / Apprehensive.
- **Friction**: Courier arriving outside scheduled delivery window.
- **Opportunity**: Morning / evening 3-hour delivery slot selection.

## 10. Returns & Exchanges
- **Activity**: Requests return or size replacement.
- **Emotion**: Frustrated.
- **Friction**: 7-10 day wait for return parcel to reach hub before replacement is sent.
- **Opportunity**: 1-Click Doorstep Instant Replacement Swap.\n
