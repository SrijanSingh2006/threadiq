# Figma UI Specification & Handoff Guide

## Design Tokens & Palette
- **Brand Primary**: Indigo/Violet `#6366F1`, Hover `#4F46E5`.
- **Fashion Accent**: Berry Pink `#FF3F6C`, Hover `#E02D57`.
- **Neutral Dark**: `#121212`, Charcoal `#1E1E24`.
- **Neutral Light**: `#F8FAFC`, Border `#E2E8F0`.

## Typography Scale
- Heading 1: Inter 24px Bold (Tracking -0.02em).
- Heading 2: Inter 18px Bold.
- Body Text: Inter 13px Regular (Leading 1.5).
- Micro / Captions: Inter 11px Medium.\n
