# Agile Scrum Delivery Workflow

## Internal Kanban Board Stages
1. **Backlog**: Unscheduled user stories.
2. **To Do**: Committed sprint backlog items.
3. **In Progress**: Active engineering / design implementation.
4. **In Review**: Pull request code review & UX design review.
5. **QA**: Test case execution in staging environment.
6. **Blocked**: Tasks with external or contractual impediments.
7. **Done**: Accepted by Product Manager against Gherkin criteria.\n
