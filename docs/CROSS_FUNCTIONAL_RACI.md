# Cross-Functional RACI Responsibility Matrix

## Role Definitions
- **R (Responsible)**: Executes the work.
- **A (Accountable)**: PM with approval authority.
- **C (Consulted)**: Subject matter expert providing input.
- **I (Informed)**: Stakeholders kept updated.
