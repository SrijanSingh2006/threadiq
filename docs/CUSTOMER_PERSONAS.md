# Fashion E-Commerce Customer Personas

## Persona 1: Trendsetter Tara
- **Demographics**: Age 21, College Student / Content Creator, Mumbai.
- **Segment**: Gen Z Trendsetter.
- **Shopping Motivation**: Desires viral aesthetic outfits seen on Reels and TikTok without overspending.
- **Frustrations**: Studio lighting hiding sheer fabric drape; inconsistent sizing across fast-fashion drops.
- **Return Behavior**: Returns 25% of orders due to bodycon length or waist fit.

## Persona 2: Workwear Sneha
- **Demographics**: Age 32, Senior Marketing Manager, Bengaluru.
- **Segment**: Premium Wardrobe.
- **Shopping Motivation**: High-quality, wrinkle-resistant capsule wardrobe for hybrid work.
- **Frustrations**: Fabric shrinkage post-wash; lack of transparent fabric composition info.
- **Return Behavior**: Low return rate (8%), primarily exchanges for alternative colors.

## Persona 3: Budget-Conscious Rohan
- **Demographics**: Age 20, Engineering Student, Pune.
- **Segment**: Value Seeker.
- **Shopping Motivation**: Maximum branded daily wear within a ₹3,000 monthly budget.
- **Frustrations**: Out-of-stock sizes during mega sales; hidden convenience fees.
- **Return Behavior**: Moderate (14%); avoids returns if return pickup fee applies.

## Persona 4: Festive Curator Anjali
- **Demographics**: Age 38, Architect & Family Planner, Delhi NCR.
- **Segment**: Festive Shopper.
- **Shopping Motivation**: Handcrafted artisanal ethnic wear for family celebrations.
- **Frustrations**: Garments arriving late for festivals; colors differing from photos.
- **Return Behavior**: High-stakes returns if delivery SLA is breached.

## Persona 5: Athletic Varun
- **Demographics**: Age 27, Tech Consultant & Marathon Runner, Hyderabad.
- **Segment**: Activewear.
- **Shopping Motivation**: Functional sweat-wicking gym apparel and durable running sneakers.
- **Frustrations**: Misleading shoe sole cushioning claims; chafing seams.
- **Return Behavior**: Returns footwear if arch width feels restrictive.\n
