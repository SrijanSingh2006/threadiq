# KPI & Metrics Dictionary

## Commerce Product KPIs
- **Purchase Conversion Rate (%)**:
  $$\text{Conversion Rate} = \frac{\text{Unique Users with 'purchase_completed'}}{\text{Unique Users with 'homepage_viewed'}} \times 100$$
  - Target: $\ge 4.5\%$
- **Cart Abandonment Rate (%)**:
  $$\text{Abandonment Rate} = \frac{\text{Unique 'added_to_cart'} - \text{Unique 'checkout_started'}}{\text{Unique 'added_to_cart'}} \times 100$$
  - Target: $\le 60.0\%$
- **Apparel Return Rate (%)**:
  $$\text{Return Rate} = \frac{\text{Total Return Requests}}{\text{Total Delivered Orders}} \times 100$$
  - Target: $\le 12.0\%$ (Reduced from $18.4\%$)
- **Catalogue Completeness Score (%)**:
  Average percentage of mandatory product attributes (SKU, fabric, dimensions, care) filled upon ingestion. Target: $\ge 95\%$.\n
